## Q2

طلع Array فيها الأرقام الأكبر من 20.

```js
const nums = [10,25,5,30,15,40];

// filter is the answer...
const result = nums.filter((num)=>{
    return num > 20;
});

console.log(result);
```

## Q3

هات أول شخص عمره أكبر من 25.

```js
const users = [
    {name:"Ali", age:20},
    {name:"Sara", age:28},
    {name:"Omar", age:30}
];

// find is the answer to return the first element that meet the condition
const user = users.find((item)=>{
    return item.age > 25;
});

console.log(user);
```

## Q4

حوّل كل الأسماء لـ Uppercase.

```js
const names = ["ali","mona","ahmed"];

// we can use map and filter and they will 
// produce the same result here but i prefer map here in this situation.
// map is the answer...
const result = names.map((name)=>{
    return name.toUpperCase();
});

console.log(result);
```

# Part 4 - To Do

## عندك الـ Array دي

```js
const fruits = ["Apple","Banana","Orange"];
```

### 1)

اطبع كل عنصر باستخدام `for...of`

// Answer...
for(let fruit of fruits){
	console.log(`${fruits.indexOf(fruit)} -> ${fruit}`);
}

---

### 2)

اطبع الـ Index باستخدام `for...in`

// Answer...
for(let fruit in fruits){
    console.log(`${fruit} -> ${fruits[fruit]}`);
}
---

### 3)

اطبع بالشكل ده باستخدام `forEach`

```
0 -> Apple
1 -> Banana
2 -> Orange
```

// Answer...
fruits.forEach(fruit => {
    console.log(`${fruits.indexOf(fruit)} -> ${fruit}`);
})
